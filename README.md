# Chat Cliente-Servidor con Sockets y SQLite

## Descripción
Aplicación básica en Python que implementa comunicación cliente-servidor mediante sockets TCP.
Los mensajes enviados por el cliente se almacenan en una base de datos SQLite.

## Tecnologías
- Python
- Sockets
- SQLite3

## Funcionalidades
- Envío de múltiples mensajes
- Persistencia en base de datos
- Respuesta del servidor con timestamp
- Manejo de errores

## Ejecución
1. Ejecutar servidor:
   python server.py

2. Ejecutar cliente:
   python cliente.py
